# 번역문 표시 정규식 · 개인용 0.3.1

`translation_regex_me`는 마리나라 번역문에 기존 표시 정규식을 적용하는 개인 확장입니다. 정규식 표시 기능에 더해 끊긴 번역 이어서 처리와 긴 원문 분할 번역을 제공합니다. 번역 작업은 저장된 번역 필드를 갱신하며 메시지 원문과 정규식은 변경하지 않습니다.

## 설치와 사용

1. GitHub 확장 관리에는 저장소 기본 주소를 사용할 수 있도록 루트에도 `manifest.json`과 `extension.js`를 제공합니다. 빌드·패키징 시 `dist/`와 바이트가 같도록 동기화합니다. Fetchy에서는 `dist/`의 `manifest.json`과 `extension.js`가 함께 있는 폴더를 사용합니다. ZIP 가져오기 방식에서는 `translation_regex_me.personal-extension.zip`을 개인 확장에서 가져옵니다.
2. 전체 페이지 접근 권한을 확인하고 확장을 켭니다. 가져오기 직후에는 꺼져 있습니다.
3. 기존 표시 정규식이 켜진 롤플레이 채팅에서 내장 번역을 사용합니다. 메시지 아래 복사·번역 아이콘 줄의 설정 슬라이더 뒤에 붙는 **점선 큐브**를 누르면 해당 번역문에 정규식을 적용하고, 다시 누르면 원래 번역문으로 돌아갑니다. 툴팁에 “길게 눌러 설정”도 안내합니다.
4. 점선 큐브를 **600ms 길게 누르거나 우클릭**하면 화면 중앙의 설정 모달이 열립니다. 오른쪽 가장자리의 작은 **점선 큐브 런처**로도 설정을 열고 닫을 수 있습니다. 런처는 44px 터치 영역이며 기본 위치는 화면 중간입니다. 위아래로 드래그하고 **700ms 길게 누르면 위치를 초기화**합니다. 위치는 세션 중만 유지하며 화면·키보드 크기와 감지된 입력창 위쪽으로 제한합니다. 공간이 없으면 런처를 잠시 숨깁니다. **플로팅 런처 표시**는 기본 켜짐이며 꺼도 메시지 큐브의 길게 누르기·우클릭 설정 진입은 유지됩니다. 런처에서 연 설정에는 메시지별 번역 작업을 표시하지 않습니다. **닫기**, 바깥 영역 탭, **Esc**로 닫을 수 있습니다. **자동 적용은 기본 꺼짐**이며 필요할 때만 켭니다. 0.1의 `enabled` 설정도 자동 적용으로 승계하지 않습니다. **이어서 번역**, **나눠서 다시 번역**, 대화 모드 적용도 여기서 선택합니다. **번역이 끊겼으면 자동으로 이어서**도 기본 꺼짐이며 정규식 자동 적용과 별도 설정입니다. 기존 자동 적용·대화 모드 설정값은 그대로 유지됩니다.
5. 작은 점과 툴팁으로 적용 중·적용 완료·실패를 구분합니다. 실패 시 원래 번역문이 유지되며 다음 확인 때 재시도합니다. 실패 버튼을 누르면 즉시 재시도합니다. API 저장 전이면 “저장된 번역문 없음”, 지원하지 않는 화면이면 “지원하는 번역 표시 영역 없음”을 표시합니다.

수동 선택은 현재 채팅·메시지·스와이프별로 기억합니다. 다른 스와이프는 기본 설정을 따르고, 이전 스와이프로 돌아오면 그 선택을 복원합니다. 설정 변경·채팅 이동·확장 재시작 시 선택은 초기화됩니다. 캐릭터 전용 규칙은 채팅/프리셋의 정규식 스코프 설정도 따라갑니다.

대화 모드는 기본 꺼짐입니다. 켜더라도 `translationSource` 또는 다듬기 확장의 `translationPolisherLongSource`가 메시지 원문과 정확히 같은 번역만 적용합니다. 마리나라는 보통 정규식으로 가공한 HTML을 번역하므로 출처가 다르거나 불명확한 번역에는 중복 적용하지 않습니다.

## 동작

- API의 현재 스와이프 `extra.translation`을 사용합니다. DOM에서 지워진 `<status>` 같은 태그를 복구해서 변환합니다.
- 서버 정렬 순서, 활성화, ai_output 배치, display/both, 캐릭터 disabled/exclusive/chat, 채팅 우선 프리셋 기본값, 대상 프리셋, 깊이, 안전성 검사, trimStrings와 원본 매크로 엔진을 따릅니다.
- 별도 번역 칸과 본문을 교체하는 번역 전용 표시를 지원합니다. API의 표시 모드·현재 원문·번역 출처를 확인한 뒤 원래 노드를 숨기고 형제 Shadow DOM에 결과를 표시합니다. 원래 자식은 보존하고 실패·토글 해제·제거 시 복원합니다.
- 스타일은 메시지 내부에만 스코프를 붙이고 Shadow DOM에 격리합니다. HTML 허용 목록은 호스트와 동일하며, script/on* 등의 실행 코드는 제거합니다.
- 확장이 보내는 요청은 same-origin `/api`로 제한합니다. 번역 공급자 호출은 마리나라 서버가 사용자의 기존 설정으로 수행합니다. 이미지 및 CSS의 URL 리소스는 차단하며 포함된 PNG/JPEG/GIF/WebP/AVIF만 허용합니다. 외부 링크는 비활성화합니다.
- 로컬 저장소에는 자동 적용·대화 모드·자동 이어 번역·플로팅 런처 표시의 네 설정만 저장합니다. 번역 공급자 키를 새로 저장하거나 로그에 남기지 않습니다. HTTP 환경에서도 동작하며 UUID·보안 컨텍스트 API를 요구하지 않습니다.
- 자동 적용·자동 이어 번역 또는 수동 실행 선택이 있을 때 API를 약 2초 간격으로 확인합니다. 모든 자동 옵션이 꺼진 수동 기본 상태에서는 작업을 선택하기 전 API를 호출하지 않습니다. 규칙·프리셋·채팅 정보 캐시는 최대 15초이며 **규칙 새로고침**으로 즉시 비웁니다. 호스트 스토어/쿼리 이벤트가 있으면 더 빨리 무효화합니다.

## 이어서 번역과 나눠서 다시 번역

- 큐브를 길게 누르거나 우클릭해 작업을 선택합니다. 현재 채팅 metadata의 공급자·출력 언어·연결·시스템 프롬프트·DeepL/DeepLX 설정을 그대로 사용합니다. 다른 모델을 따로 설정할 필요가 없습니다.
- **나눠서 다시 번역**은 현재 원문 전체를 약 3,000자씩 문단, 문장, 공백 순서로 나눕니다. 공백 없는 긴 문자열만 문자 경계에서 나눕니다. 모든 태그 블록을 보호하므로 표시 정규식이 쓰는 `<status>…</status>`도 청크 중간에서 잘리지 않습니다. 태그 블록 자체가 더 크면 한 청크로 유지하며 공급자 요청 한도를 넘으면 중단합니다.
- 태그·속성은 자리표시자로 바꾼 뒤 복원합니다. 내용은 번역하되 자리표시자가 누락·중복·재정렬되면 해당 청크 전체를 원문으로 보존하고 개수를 안내합니다. 보존된 부분에는 미번역 텍스트가 남을 수 있습니다.
- **이어서 번역**은 번역이 원문의 정확한 앞부분이거나, 번역 끝에 원문에서 한 번만 등장하는 동일한 태그 블록(16자 이상)이 남아 있을 때 그 뒤만 번역합니다. 길이 비율만으로 원문 위치를 결정하지 않습니다. 언어가 달라 문장 중간의 위치를 확신할 수 없으면 **나눠서 다시 번역**을 안내합니다.
- 자동 끊김 판정은 태그를 제외한 원문이 600자 이상이고 번역/원문 길이가 0.45 미만이거나, 원문 300자·번역 40자 이상에서 원문은 문장부호로 끝나는데 번역은 그렇지 않은 경우입니다. 언어·문체에 따라 오탐할 수 있는 휴리스틱이며 정확한 번역 완결성 판정은 아닙니다. 같은 원문·스와이프·번역은 세션 중 한 번만 자동 시도하고 자신의 저장 결과도 재시도하지 않습니다. 숨긴 번역은 자동 처리하지 않습니다.
- `청크 n/m`, **취소**, 실패·취소 후 **부분 결과 저장/버리기**를 제공합니다. 자동 저장은 전체 완료 후에만 합니다. 부분 저장은 사용자가 선택하면 기존 번역을 완료된 청크까지의 결과로 바꾸며, 이어서 작업에서는 기존 앞부분도 포함합니다. 부분 결과는 메모리에만 남고 채팅 이동·확장 종료 시 버립니다.
- 저장은 `translation`, 현재 원문의 `translationSource`, `translationHidden:false` 세 필드만 PATCH하고 정규식을 다시 적용합니다. 청크마다 및 저장 직전 원문·활성 스와이프·기존 번역을 재확인합니다. 다른 작업이 바꾼 번역은 덮어쓰지 않으며, 저장 실패 시 기존 번역을 유지합니다. 명시적 스와이프 번호로 저장하되 서버가 조건부 갱신을 제공하지 않아 마지막 확인과 저장 사이의 동시 수정까지 원자적으로 막지는 못합니다.

## 말랑 리모콘과 함께 사용

런처의 고정 `id`와 `data-testid`는 모두 `translation-regex-launcher`입니다. 문서에 하나만 유지하며 리모콘의 고르기 모드로 등록할 수 있습니다. 리모콘이 숨긴 뒤에도 프로그램적 `click()`으로 설정을 열고 닫습니다. 외부 숨김 클래스·표시 스타일은 위치 변경, 설정 토글, 노드 재부착 시 보존합니다. 런처 표시 설정은 리모콘의 숨김 상태와 독립적이며 모달 위치는 런처의 표시 여부에 의존하지 않습니다.

## 번역 다듬기와 함께 사용

API의 `extra.translation`이 기준이며 `translationPolisherOutput` 같은 보조 결과를 대신 읽지 않습니다. `translationPolisherLongSource`가 현재 원문과 같으면 긴 번역의 출처도 허용합니다. 다듬기 확장의 DOM 변경은 fingerprint로 비교해 다시 적용하며 동일한 변경에는 재렌더하지 않습니다. `[data-translation-polisher-ui]` 컨트롤은 변경하지 않고 번역 영역 안에 대화형 다듬기 UI가 있으면 그 영역을 숨기지 않습니다. 다듬기 필드는 저장 시 보존합니다. 두 확장의 번역 작업을 동시에 실행하는 것보다 한 작업을 끝낸 뒤 다음 작업을 실행하는 편이 적절합니다.

## 개발

Node.js 26에서 검증했습니다. `npm ci`, `npm test`, `npm run package` 순서로 빌드·검증·패키징할 수 있습니다. 설치에는 일반적으로 패키지 레지스트리가 필요하지만 이번 작업에서는 로컬 캐시만 사용했습니다. 실행 ZIP은 네트워크로 의존성을 다운로드하지 않습니다.

`src/regex.ts`는 원본 분기별 파일/줄 주석을 포함합니다. `vendor/UPSTREAM.json`은 읽기 전용 참조 원본의 SHA-256입니다. `scripts/import-reference.py`는 명시된 마리나라 참조 경로에서만 복사합니다. 참조 경로 없이도 동봉 소스만으로 빌드할 수 있습니다.

## 적용 범위와 확인 상태

`data-message-id` 안의 `.translation-text`, 또는 `translationDisplayOnly`와 번역 출처가 확인된 단일 `.mari-message-content`를 처리합니다. 메시지 식별이 불가능하거나 본문이 여러 조각인 화면, 편집 중인 화면, 본문에 대화형 명령 결과가 들어 있는 화면은 원래 표시를 유지합니다. `.mari-message-actions`가 있는 AI 메시지에 실행 버튼을 붙이며, 액션 줄이 없는 화면은 수동 버튼을 추가하지 않습니다. HTML 패널 및 주변 텍스트를 표시하며, 변환 결과에 대한 마리나라 고유 Markdown·화자 색상·카드 이미지 해석 파이프라인 전체를 재현하지는 않습니다.

`npm run qa:browser`는 외부 요청을 차단한 가짜 호스트에서 360px 레이아웃을 확인하는 스크립트입니다. 런처의 44px 영역·드래그·입력창 비겹침·숨김 상태 클릭, 메시지 큐브의 짧은 탭·길게 누르기·우클릭, 모달 닫기, 모달의 뷰포트 내 중앙 배치와 입력창 분리, 닫기의 44px 영역, 큐브의 마지막 자식 배치·호스트와 같은 크기 및 기존 액션 간 겹침·줄바꿈을 검사하도록 구성했습니다. 이번 환경에서는 Chromium 실행이 샌드박스 소켓 제한으로 막혀 실제 레이아웃 검증을 완료하지 못했습니다. 자동 테스트와 미확인 항목의 자세한 구분은 저장소의 `REPORT.md`를 참고하세요. 개인 설치용이며 공개 배포용 패키지는 아닙니다.
